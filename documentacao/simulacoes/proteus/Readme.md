# Simulação do Atuador Piezoelétrico no Proteus

Esta pasta contém o arquivo da simulação realizada no **Proteus** durante o desenvolvimento da prova de conceito do sistema de navegação vibrotátil.

A simulação foi utilizada como etapa intermediária de avaliação do circuito de acionamento com atuador piezoelétrico, antes dos testes físicos realizados posteriormente durante o desenvolvimento do protótipo.

## Arquivo da simulação

O arquivo disponibilizado nesta pasta corresponde ao projeto utilizado no Proteus para representar e verificar o comportamento do circuito associado ao atuador piezoelétrico.

Para abrir e editar a simulação, é necessário utilizar uma versão compatível do Proteus Design Suite.

## Contexto no desenvolvimento

O atuador piezoelétrico foi investigado durante as etapas iniciais de desenvolvimento como uma alternativa para geração de estímulos táteis.

Posteriormente, os testes experimentais também envolveram motores vibratórios, que foram adotados nas etapas subsequentes da prova de conceito.

## Observação

Esta simulação representa uma etapa específica do processo de desenvolvimento e não corresponde à configuração física completa do sistema com oito motores vibratórios.
