# Simulação no Wokwi

Esta pasta contém os arquivos referentes à simulação realizada no **Wokwi** durante o desenvolvimento da prova de conceito do sistema de navegação vibrotátil.

A simulação foi utilizada como etapa de validação prévia da lógica de funcionamento do sistema embarcado, permitindo verificar o comportamento das saídas associadas às direções antes da montagem física com a ESP32.

## Arquivos

O arquivo compactado disponível nesta pasta contém uma cópia dos arquivos utilizados na simulação.

## Simulação online

A versão interativa da simulação pode ser acessada diretamente no Wokwi:

**Link:** https://wokwi.com/projects/431701563343005697

## Observação

A simulação representa uma etapa intermediária do processo de desenvolvimento e foi utilizada para verificar a lógica de acionamento do sistema. Os testes físicos posteriores foram realizados com a ESP32 e os componentes descritos no trabalho.
